# Sending setup checklist

Open items need the founder; nothing here has been done.

1. [ ] Choose a separate sending domain (not the main company domain; main domain is TBD in the profile). Cost needs approval.
2. [ ] Create one or two mailboxes on it in the founder's real name.
3. [ ] Publish SPF, DKIM, and DMARC records for the sending domain; verify alignment with a test message.
4. [ ] Set a custom tracking or link domain, or switch off link tracking.
5. [ ] Warm up for about two weeks before the first campaign send.
6. [ ] Daily volume limit per mailbox. Proposal (assumption, founder to approve): start at 10 new contacts a day, cap at 30.
7. [ ] Pick a sequencing tool. None is in the profile. Options: HubSpot sequences if the plan includes them, or a dedicated tool; either way confirm it honors unsubscribes automatically.
8. [ ] Build the suppression list: 38 customers and open deals from HubSpot, Stripe customers, Intercom contacts, all past unsubscribes and bounces.
9. [ ] Add the footer with the company's valid postal address and a working unsubscribe link; test that the link works and keeps working at least 30 days.
10. [ ] Send test: 2 subject lines on 20 US contacts each before scaling. Founder approves the first send of each sequence and list.
11. [ ] Daily: triage replies into interested, referral, objection, not now, unsubscribe; update HubSpot.
