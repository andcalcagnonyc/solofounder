# SEO and Generative Engine Optimization

Make the company discoverable where buyers research: classic search engines and AI answer engines. Build topical authority with content that is correct, specific, and citable.

## Before starting

1. Read `solofounder/company-profile.md`. If it does not exist, stop, tell the founder that the `start` intake comes first, name the `start` skill, and run it before anything else.
2. Take HQ country, entity type, stage, currency, and tool stack from the profile. Never assume a jurisdiction, a currency, or a tool.
3. Check `solofounder/decision-log.md` for earlier decisions that constrain this work.

## Inputs

- ICP, messaging pillars, competitors, existing site and content
- Access to search and analytics data where connected

## Workflow

1. Map buyer questions across the journey: problem, solution category, comparison, implementation, and pricing. Include the prompts buyers put to AI assistants.
2. Research keywords and cluster them into topics; assign one page per cluster with intent, difficulty, and business value.
3. Audit technical health: indexability, speed, structured data, internal links, duplicate content, and crawler access for AI engines.
4. Measure current AI-answer visibility: run the priority prompts across the main assistants, record whether the company is cited and which sources are cited instead.
5. Write a brief for each page: question answered, unique evidence, structure, entities to cover, internal links, schema.
6. Draft content with direct answers up front, original data or examples, clear definitions, comparison tables, and cited sources; the founder reviews for accuracy.
7. Build authority off-site: listings, comparison sites, communities, partner pages, and publications that AI engines cite for the category.
8. Report monthly: rankings, organic traffic, AI citations, and leads from organic.

## Deliverables

- Topic and keyword map
- Technical audit with fixes ranked
- AI-visibility baseline and prompt set
- Content briefs and drafts
- Monthly organic report

## Founder approval gates

- Publication of each article
- Claims, statistics, and comparisons

## Guardrails

- Act through connected tools where they exist (see `CONNECTORS.md`); otherwise produce ready-to-use files and exact manual steps.
- Ask before any action that contacts someone outside the company, spends money, or cannot be undone.
- Mark assumptions as assumptions. State a fact about the company only when it is in the profile or the founder said it in this session; otherwise ask. Never invent facts, metrics, customers, quotes, or citations.
- Append each material decision to `solofounder/decision-log.md` with date, options considered, and rationale.
- Save deliverables under `solofounder/marketing/` with dated filenames.

## Hand-offs

- `marketing-website` for technical fixes
- `marketing-demand-generation` for distribution
